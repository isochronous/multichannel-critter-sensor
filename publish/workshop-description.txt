Adds a Multichannel Critter Sensor: a room-based critter and egg counter that outputs over an Automation Ribbon and lets you choose exactly which species and egg types to count.

[h2]What it does[/h2]
The sensor counts critters and eggs in its room, like the vanilla Critter Sensor, and writes a 4-bit value to its ribbon output:
[list]
[*][b]Bit 1[/b]: green when the tracked count passes the threshold (or the critter count, in separate-thresholds mode)
[*][b]Bit 2[/b]: green when the egg count passes its own threshold (separate-thresholds mode)
[*][b]Bit 3[/b]: a one-tick green pulse each time the tracked count rises
[*][b]Bit 4[/b]: a one-tick green pulse each time the tracked count falls
[/list]

[h2]Filters and thresholds[/h2]
[list]
[*]Tick [i]Count Critters[/i] and pick species from the list of discovered baggable critters, or leave [i]All[/i] on so newly discovered species count automatically.
[*]Tick [i]Count Eggs[/i] and pick egg types the same way.
[*]Thresholds use the vanilla threshold controls (above/below, number field, slider, 0 to 64), either one combined threshold or separate critter and egg thresholds.
[*]Connect the output with an Automation Ribbon; a plain wire overloads when more than one bit is on, as with the Ribbon Writer.
[*]Supports the copy-settings tool; all settings are saved with the building.
[/list]

Unlocked by [b]Multiplexing[/b]. Costs 50 kg Refined Metal and 50 kg Plastic. Found under Automation > Sensors, next to the vanilla Critter Sensor.

[h2]Compatibility[/h2]
Works with the base game and all DLCs, on build 744825 (U59) or newer. No dependencies. A new game is not required.
